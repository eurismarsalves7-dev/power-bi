# Projeto 01 — Análise de Acidentes de Trânsito nas Rodovias do Brasil

Projeto acadêmico desenvolvido durante a formação em Ciência de Dados.

## Objetivo
Dashboard interativo no Power BI para analisar acidentes registrados em rodovias federais brasileiras, identificando padrões, regiões críticas, horários de maior incidência e fatores contribuintes.

## Tecnologias
- Power BI
- Power Query
- DAX
- Excel
- Dados Abertos da PRF

## Metodologia
1. Coleta dos dados da PRF em CSV.
2. Limpeza e padronização no Power Query.
3. Modelagem relacional com dimensões de Data, Local e Tipo e tabela fato de Acidentes.
4. Criação de KPIs com DAX.
5. Desenvolvimento de mapas, gráficos temporais, barras e cartões.
6. Segmentação por período, UF e tipo de acidente.

## Resultados e insights
Foram analisados mais de 60 mil registros. O projeto permitiu explorar distribuição geográfica, períodos e horários de maior incidência, gravidade por região e relação com condições climáticas.
