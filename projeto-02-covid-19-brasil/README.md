# Projeto 02 — Análise de Doenças e Impacto da COVID-19 no Brasil

Projeto acadêmico desenvolvido durante a formação em Ciência de Dados.

## Objetivo
Dashboard no Power BI para analisar a evolução da COVID-19 no Brasil, considerando casos, óbitos, vacinação e diferenças regionais.

## Tecnologias
- Power BI
- Power Query
- DAX
- Séries temporais
- Dados públicos do Ministério da Saúde / OpenDataSUS

## Metodologia
1. Extração de dados epidemiológicos em CSV e API pública.
2. Tratamento e normalização no Power Query.
3. Junção com dados populacionais.
4. Modelagem em estrela.
5. Medidas DAX para casos acumulados, média móvel de 7 dias, letalidade, cobertura vacinal e variação semanal.
6. Visualizações temporais, mapas por UF e comparações regionais.

## Resultados e insights
O dashboard permitiu visualizar ondas da pandemia, tendências temporais e diferenças regionais de vacinação e mortalidade.
